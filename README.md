# TautWeekly WebUI

A modern, lightweight web management interface for **TautWeekly**, built for Docker and Unraid.

TautWeekly WebUI provides a centralized dashboard for managing your TautWeekly installation, monitoring service health, editing configuration, managing backups, viewing logs, and sending test emails — all from a simple browser-based interface.

## ✨ Features

* 📊 **Dashboard** — Quickly view TautWeekly and service status
* ⚙️ **Configuration** — Manage TautWeekly settings through the web interface
* 👥 **Tautulli Integration** — Access configured users for TautWeekly
* 📧 **Test Email** — Send a TautWeekly test email directly from the WebUI
* 📜 **Log Viewer** — View recent Docker and TautWeekly logs
* 💾 **Backup Management** — Create, view, and delete TautWeekly configuration backups
* ❤️ **Service Health** — Monitor TautWeekly, Plex, Tautulli, and related services
* 🐳 **Docker Ready** — Designed to run cleanly alongside TautWeekly in Docker
* 🖥️ **Unraid Ready** — Built with Unraid deployments in mind
* 🌐 **Simple Web Interface** — Access everything from your browser

## 🚀 Getting Started

TautWeekly WebUI is designed to work alongside your existing TautWeekly installation.

**WebUI:** `http://YOUR-UNRAID-IP:8788`

**Container:** `tautweekly-manager`

## 📦 Requirements

* Docker
* Unraid or another Docker-compatible environment
* A working TautWeekly installation
* Tautulli for user integration and newsletter management

## 📌 Version

**v1.0.0 — Initial Stable Release**

## 🔗 TautWeekly

TautWeekly is the underlying newsletter application that powers the system:
TautWeekly WebUI does not replace TautWeekly — it provides a convenient web-based management layer on top of it.
